Kostenloses Hosting (GitHub & Netlify)

Sie können diese Website vollkommen kostenlos hosten, sodass alle Teilnehmer während des Tandem-Abends einfach per Handy auf einen Link oder QR-Code zugreifen können.

Option 1: GitHub Pages (Empfohlen)

  1. Erstellen Sie ein kostenloses Konto auf github.com.
  2. Erstellen Sie ein neues Repository (z.B. tandem-icebreakers).
  3. Laden Sie diese HTML-Datei hoch und benennen Sie sie genau index.html.
  4. Gehen Sie zu Settings → Pages und wählen Sie den Branch main aus.
  5. Klicken Sie auf Save. In ca. 1 Minute erhalten Sie Ihre kostenlose Webadresse!

Option 2: Netlify Drop (Ohne Account in 30 Sekunden)

  1. Gehen Sie auf app.netlify.com/drop.
  2. Speichern Sie diesen Code in einem Ordner als index.html.
  3. Ziehen Sie den Ordner einfach per Drag & Drop auf das Netlify-Feld.
  4. Ihre Seite ist sofort online! Sie erhalten direkt einen zufälligen Link.
Tipp für den Tandem-Abend:

Erstellen Sie aus Ihrer generierten Web-URL einen kostenlosen QR-Code (z.B. über qr-code-generator.com) und drucken Sie diesen für die Tische aus!
