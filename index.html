Kostenloses Hosting (GitHub Pages / Netlify)

Sie können diese Webseite **100% kostenlos** online stellen, damit alle Kursteilnehmer per Smartphone direkt darauf zugreifen können.

Option 1: GitHub Pages

  1. Registrieren Sie ein kostenloses Konto auf github.com.
  2. Erstellen Sie ein neues Repository (z.B. tandem-icebreakers).
  3. Klicken Sie auf **Add File $\rightarrow$ Upload Files** und laden Sie diese Datei als index.html hoch.
  4. Gehen Sie zu **Settings $\rightarrow$ Pages**, wählen Sie den Branch main und klicken Sie auf **Save**.
  5. Nach etwa 1 Minute ist Ihre Webseite unter Ihrer kostenlosen GitHub-URL erreichbar!

Option 2: Netlify Drop (Direkt ohne GitHub)

  1. Speichern Sie diesen Quellcode in einem Ordner als Datei namens index.html.
  2. Öffnen Sie app.netlify.com/drop im Browser.
  3. Ziehen Sie den Ordner mit der Datei einfach per Drag & Drop in das Feld.
  4. Ihre Seite ist sofort unter einem Link online!
